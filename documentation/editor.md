# The graph editor

The editor is where patches are built. This covers moving around a patch,
working with ports and macros, and the commands available from the menus.

If you have not built a patch before, start with
[Getting started](getting-started.md).

## The window

The **menu bar** carries File, Edit, View, Options and Help.

The **toolbar** along the top has Quick sounds, undo and redo, the zoom
controls with the current zoom level, and **Organize**.

The **canvas** fills the middle. Right-click anywhere on it to add a node.

The **Macros** panel on the right lists the knobs you have promoted, and the
**Map** below it shows the whole patch in miniature with your current view
marked, which is the quickest way to find your way around a large graph.
**Open** expands it.

The **transport** along the bottom has Play and Stop, Export to WAV, and
shortcuts for saving and opening a patch.

## Nodes

Add a node by right-clicking the canvas and picking from the categories. Drag a
node's header to move it, and its corner to resize it. Select a node and press
Delete or Backspace to remove it.

Each node shows its input ports on the left and its output ports on the right.
The **?** button in a node's header opens that node's own documentation, with a
description and a worked wiring example. This is usually faster than looking a
node up elsewhere, and it is the best way to find out what an unfamiliar port
expects.

### Wiring

Drag from an output port to an input port to connect them. A patch must end at
exactly one **Audio Out** node, and it cannot contain a loop - a signal cannot
feed back into something that produces it, directly or through a chain.

### Knobs

Every input port with nothing wired into it gets a slider on the node, so you
can set a value without adding a node to supply it. Connect something to that
port and the connection takes over; disconnect it and the knob applies again.

### Macros

A knob you keep reaching for can be promoted with the **+** next to it. It then
appears in the Macros panel as a named slider for the patch as a whole, and on
the quick screen.

Macros matter beyond convenience. When a patch is used as a node inside another
patch, each of its macros becomes an input port on that node. Deciding what to
promote is deciding what your instrument or effect exposes to whoever uses it.

## Moving around

| Action | How |
|---|---|
| Zoom | Ctrl and scroll, the toolbar buttons, or Ctrl+= and Ctrl+- |
| Reset zoom | **View > Reset Zoom** |
| Return to the patch | **View > Center View** |
| Tidy the layout | **Organize** in the toolbar, or **View > Organize Layout** |

**Organize** lays the graph out automatically. It is most useful on a patch
written by hand in Diesel or generated by a script, where nodes have no
positions and arrive stacked at the origin.

## Undo

Every structural edit can be undone: adding and deleting nodes, wiring and
unwiring, moving things, and macro changes. Ctrl+Z undoes, Ctrl+Shift+Z redoes.

## Playing

**Play** auditions the patch live; **Stop** ends it. A patch that never ends
keeps playing until stopped. One built around a one-shot envelope plays once
and finishes on its own.

Under **Options**, you can choose the **Output Device** and **Input Device**,
set **Playback Quality** and **Latency**, and set a **Render Limit**. Lower
latency is more responsive but more likely to break up; raise it if playback
stutters.

## Reusing a patch as a node

Any saved patch can be added to another patch as a single node, from the
**Patches** category. Its Audio Out becomes the node's output, and each of its
macros becomes an input port.

This is how you build an instrument or an effect once and use it everywhere.
The patch is embedded by value rather than linked, so a patch that uses it
still opens on a machine that has never seen the original.

## Keyboard shortcuts

### File

| Shortcut | Action |
|---|---|
| Ctrl/Cmd+S | Save Patch |
| Ctrl/Cmd+O | Open Patch |

### Edit

| Shortcut | Action |
|---|---|
| Ctrl/Cmd+Z | Undo |
| Ctrl/Cmd+Shift+Z | Redo |
| Delete / Backspace | Delete selection |

### View

| Shortcut | Action |
|---|---|
| Ctrl/Cmd+= | Zoom in |
| Ctrl/Cmd+- | Zoom out |

### Tracker grid

| Keys | Action |
|---|---|
| Z S X D C V G B H N J M | One octave of white and black keys |
| Q 2 W 3 E R 5 T 6 Y 7 U I 9 O 0 P | One octave up from those |
| Arrow keys | Move the cursor |
| Home / End | Jump to the first or last step |

The same list is in the application under **Help > Keyboard Shortcuts**.

## Built-in documentation

**Help > Documentation** opens the reference that ships with the editor. It has
an article for every node you can place, each with a description and a worked
wiring example, plus guide articles on the editor's own features. Any node's
**?** button jumps straight to its article.

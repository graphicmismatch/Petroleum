# Petroleum user documentation

How to use Petroleum to design sounds and render them. For an overview of the
project and how to build it, start with the [project README](../README.md).

## Guides

- **[Getting started](getting-started.md)** - launching Petroleum, and building,
  playing and exporting a first sound from an empty canvas
- **[The graph editor](editor.md)** - working at speed: nodes and wiring, knobs
  and macros, moving around a large patch, and the keyboard shortcuts
- **[Nodes by purpose](nodes.md)** - what each category in the node menu is for
  and when to reach for it
- **[Sequencing](sequencing.md)** - the tracker, the piano roll and the MIDI
  player: writing parts, per-note effects, and driving instruments
- **[Working with samples](samples.md)** - recording and importing audio,
  multisample instruments, and the granular nodes
- **[Exporting and rendering](exporting.md)** - the export settings, the
  command-line renderer, and rendering in bulk
- **[Collaborating in real time](collaboration.md)** - hosting and joining a
  shared session, encrypted servers, and what is and isn't shared

## Reference

- **[Diesel language guide](../DIESEL.md)** - the complete reference for the
  `.dsl` text format: syntax, node fields, connections, macros, embedded
  samples, and a table of every node with its ports and defaults.
- **In-app documentation** - the editor carries its own reference. Every node
  has a "?" button in its header that opens a description and a worked wiring
  example for that node, and **Help > Documentation** opens the same reference
  with a searchable index and guide articles on the editor's features.
